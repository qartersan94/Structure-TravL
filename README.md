# 🎮 Structure TravL - Esports Arena

Plateforme esports professionnelle ultra-moderne pour 7 équipes League of Legends.

## 🚀 Installation
```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build de production
npm run build
```

## 🏆 Les 7 Équipes
